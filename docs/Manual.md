# Fork-Join Sorting Application — User Manual

## 1. Төслийн тухай

Энэхүү програм нь Java хэл дээр Fork-Join Framework ашиглан Merge Sort болон Quick Sort алгоритмуудыг parallel-р хэрэгжүүлж, эрэмбэлэлтийн явцыг мод хэлбэрээр дүрслэн харуулдаг.

## 2. Шаардлагатай програм хангамж
- JDK 23
- Apache Maven
- JavaFX 23.0.2

## 3. Төслийг ажиллуулах

### Алхам 1. Төслийг нээх

Төслийн root хавтас руу шилжинэ.

```bash
cd fork-join-sorting
```

### Алхам 2. Програмыг ажиллуулах

Maven ашиглан JavaFX програмыг ажиллуулна.

```bash
mvn clean javafx:run
```

Хэрэв команд амжилттай ажиллавал програмын график интерфейс нээгдэнэ.

## 4. Програмын үндсэн ажиллагаа

1. Эрэмбэлэх өгөгдлийг оруулна/Эсвэл random утга болон жишээнээс сонгож болно.
2. Merge Sort эсвэл Quick Sort алгоритмыг сонгоно.
3. Шаардлагатай бол threshold утгыг тохируулна.
4. Эрэмбэлэлтийг эхлүүлнэ.
5. Үр дүн болон рекурсийн модны дүрслэлийг ажиглана.

## 5. Алгоритмын тайлбар

### Merge Sort

Өгөгдлийг хоёр хэсэгт хувааж, хэсэг бүрийг рекурсив байдлаар эрэмбэлэн, эцэст нь нэгтгэдэг. Fork-Join Framework ашиглан дэд бодлогуудыг parallel ажиллуулах боломжтой.

### Quick Sort

Өгөгдлийг pivot утгаар хувааж, хоёр хэсгийг тус тусад нь эрэмбэлдэг. Fork-Join Framework ашиглан дэд бодлогуудыг parallel боловсруулна.

### Threshold

Threshold нь бодлогыг цаашид жижиг дэд бодлогууд болгон хуваах эсэхийг шийдэх босго утга юм. Дэд бодлогын хэмжээ босгоос бага үед шууд эрэмбэлэх аргыг ашиглана.

## 6. Тест ажиллуулах

Төслийн root хавтаснаас дараах командуудыг ажиллуулна.

```bash
mkdir -p out
javac -encoding UTF-8 -d out src/SortNode.java src/MergeSortTask.java src/QuickSortTask.java src/SortTrace.java tests/SortTests.java
java -cp out SortTests
```

Тест амжилттай ажиллавал тестийн үр дүн терминал дээр харагдана.

## 7. Түгээмэл асуудлууд

- **Java хувилбарын алдаа:** `java -version` командаар суулгасан Java хувилбарыг шалгана.
- **Maven алдаа:** `mvn -version` командаар Maven зөв суусан эсэхийг шалгана.
- **JavaFX програм нээгдэхгүй байх:** Maven dependency болон `pom.xml` тохиргоог шалгана.
- **Тестийн compile алдаа:** Төслийн root хавтсаас командуудыг ажиллуулж, шаардлагатай source файлууд байгаа эсэхийг шалгана.

## 8. Дүгнэлт

Энэхүү програм нь Fork-Join Framework ашиглан эрэмбэлэлтийн алгоритмуудыг parallel байдлаар боловсруулж, тэдгээрийн рекурсив бүтцийг дүрслэн ойлгоход зориулагдсан.
